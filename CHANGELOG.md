# Changelog

## v0.1.0-beta - 2026-10-24

- Adds a Motorsport-specific HUDless/UI extraction add-on for ReShade.
- Promotes scene, depth, motion-vector, HUDless and UI resource tags to the
  same Streamline frame token.
- Enables Streamline frame-based resource tagging locally in the game process.
- Rebuilds HDR-format resources when the swapchain changes.
- Includes the tested 4x fixed-mode profile and Insert overlay hotkey.
- Keeps motion tracing disabled in the public profile.
